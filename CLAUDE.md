# Sissi Fine Foods · Abbinamenti

- Il brief completo del progetto è in `PROMPT.md`: leggilo per intero prima di fare qualsiasi cosa e segui il processo che descrive (prima un piano breve, poi il mio ok).
- `data/abbinamenti.json` è l'unica fonte dei dati: non inventare né cambiare abbinamenti, motivi o prezzi.
- `reference/riferimento-artifact.html` è il riferimento funzionale, non grafico.
- Scrivi in italiano: testi del sito, commit, README e risposte.
- Il repository è pubblico: mai committare costi, margini, export di Tilby o altri dati riservati.
- Niente push su `main` (che pubblica il sito con GitHub Pages) senza chiedermelo: lavora su un branch e proponimi le modifiche.
