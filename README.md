# Abbinamenti · Sissi Fine Foods

Strumento interno del negozio Sissi Fine Foods (Viale Oriani 37F, Bologna): cerchi un prodotto e vedi con cosa abbinarlo, quali vini, cosa evitare e perché.

## Contenuto

| Percorso | Cosa contiene |
|---|---|
| `PROMPT.md` | Brief per Claude Code: obiettivo, funzioni, grafica, Render, collaudo |
| `CLAUDE.md` | Regole di lavoro per Claude Code in questo repository |
| `data/abbinamenti.json` | 127 prodotti e 12 famiglie di gusto, con abbinamenti, cose da evitare e motivi (ID e prezzi da Tilby) |
| `reference/riferimento-artifact.html` | La pagina attuale, da usare come riferimento funzionale |
| `public/brand/` | Qui va il logo `logo-sissi.svg`, con i testi convertiti in curve |

## Come partire

Apri una sessione di Claude Code su questo repository e scrivi: **"Leggi PROMPT.md e segui il brief"**.

Il sito verrà pubblicato con GitHub Pages da questo repository. Il repository è pubblico: qui non vanno mai costi, margini o export di Tilby.
